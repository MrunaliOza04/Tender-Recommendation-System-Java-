## Project Description
Whenever a company requires services or merchandise, a tender is floated. The company maintains an empaneled list of vendors. Only registered vendors can bid, and each vendor can place only one bid per tender. Multiple vendors may bid for the same tender, and the most suitable bid is selected.

This system automates the tender management process, making it faster, transparent, and easy to manage.

---

## User Roles

### 1. Administrator
- Create and manage vendors
- Create and view tenders
- View all bids for a tender
- Select the best bid

### 2. Vendor
- View available tenders
- Place bids
- Check bid status
- View bid history
